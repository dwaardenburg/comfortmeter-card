# Domain documentation

This is a single-context repo.

- **`CONTEXT.md`** (root): the glossary. Use its terms exactly in code, docs, commit
  messages and conversation. A missing or fuzzy term is a `domain-modeling` moment:
  sharpen it and write it down.
- **`documents/architecture/`**: ADRs, numbered `0001-slug.md` onwards. None yet: the
  design is still settling, so nothing becomes an ADR until a decision is hard to
  reverse, surprising and a real trade-off. Create the folder with the first one.
- **`documents/design/`**: how the card looks and why, with the numbers it copies from
  Home Assistant.
- **`documents/research/`**: findings with their sources, dated.
